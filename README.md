# Portal do Cliente — Mockup

Proposta visual do Portal do Cliente da Luminatti.

Mockup estático e autocontido: todo o HTML, CSS e JavaScript estão em [index.html](index.html),
sem dependências além da fonte Montserrat (Google Fonts). Não há backend — os dados exibidos
são fictícios, apenas para demonstração de layout e fluxo.

## Como visualizar

Abra o `index.html` direto no navegador, ou sirva a pasta localmente:

```bash
python -m http.server 8000
# depois acesse http://localhost:8000
```

## Escopo

Este repositório contém apenas a camada de apresentação para validação de design.
Não é código de produção.
